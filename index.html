📖 Как подключить за 3 минуты — инструкция
  1. Создай новую Google Таблицу (sheets.new).
  2. Меню Расширения → Apps Script, удали всё и вставь код ниже.
  3. Развернуть → Новое развёртывание → Веб-приложение; «Выполнять от имени: Я», «Доступ: Все».
  4. Скопируй выданный URL и вставь в поле выше.
function doPost(e){
  try{
    var d = JSON.parse(e.postData.contents);
    var ss = SpreadsheetApp.getActiveSpreadsheet();
    put_(ss, 'Профиль', d.profile);
    put_(ss, 'Привычки', d.habits);
    put_(ss, 'Источники дохода', d.sources);
    put_(ss, 'Операции', d.log);
    return out_({ok:true, time:new Date()});
  }catch(err){ return out_({ok:false, error:String(err)}); }
}
function put_(ss, name, rows){
  if(!rows || !rows.length) return;
  var s = ss.getSheetByName(name) || ss.insertSheet(name);
  s.clearContents();
  s.getRange(1, 1, rows.length, rows[0].length).setValues(rows);
}
function out_(o){
  return ContentService.createTextOutput(JSON.stringify(o))
    .setMimeType(ContentService.MimeType.JSON);
}

В таблице появятся листы: «Профиль», «Привычки», «Источники дохода», «Операции». После правки скрипта — повторное развёртывание.
